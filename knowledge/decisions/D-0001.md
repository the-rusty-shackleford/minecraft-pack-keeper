# D-0001 — Kept packs are re-registered under the game's own ids, required, and the order is imposed on the options list

**Decision**: At `AddPackFindersEvent` (client resources) the mod hands
the game every listed pack that exists, under the id the game's own folder
source gives it (`file/<name>`), with `PackSelectionConfig(required=true,
TOP, fixed=false)`. It then rewrites `Minecraft.options.resourcePacks`
through `Selection.imposedOn`: the kept packs as one block in the config's
order, above everything that is not a file pack and below any file pack
the player chose themselves.

**Why**: The game builds its available-pack map by putting each source's
packs into a map keyed by id, source by source, so a mod's source -- which
runs after the folder source -- replaces the folder's entry for the same
id: one entry per pack, and ours carries the *required* flag, which the
game honours by always selecting the pack and refusing to unselect it.
But the order in which the game inserts required packs it did not find in
the saved list is the map's order -- alphabetical by id -- which is not
the modpack's order, and a patch pack has to sit above the pack it
patches. The saved list is what the game reads to build the selection
(`Options.loadSelectedResourcePacks`), and NeoForge fires the event after
the options are loaded and before that call, so putting the order into the
list is exactly enough and leaves the rest of the player's options alone.

**Alternatives rejected**: *Ids of our own that sort into the order* — the
folder source's entry for the same file would remain, so each pack would
show twice and could be enabled twice. *Fixed positions* — still
alphabetical among themselves. *Reloading resources after setup with the
selection set* — a second load screen on every launch. *Shipping
`options.txt`* — what this mod replaces.

**Links**: `src/main/java/com/nfx/packkeeper/PackKeeper.java`,
`src/domain/java/com/nfx/packkeeper/domain/Selection.java`, the booth's
seven checks in `src/gametest/java/com/nfx/packkeeper/gametest/PackBooth.java`.
